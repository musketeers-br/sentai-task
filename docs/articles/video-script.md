# SentaiTask — narration script for the demo video

For the team member recording the voice-over (spec 014 US5). One row per scene of the recording
(`frontend/media/showcase.media.ts`); the captions are burned into the video. Start times assume
no time-lapse; with one, keep the order and let each sentence end before the next caption.
Total: about 60 seconds.

| # | Starts | Caption on screen | Narration (EN) | Narração (PT-BR) |
|---|---|---|---|---|
| 1 | 0:00 | A maintenance flow: checks on two servers, one join | This is SentaiTask. Instead of scheduling IRIS maintenance jobs one by one, you draw them as a flow. | Este é o SentaiTask. Em vez de agendar os jobs de manutenção da IRIS um a um, você desenha um flow. |
| 2 | 0:05 | Validated against the live instance | Before anything runs, the flow is validated against the live instance. | Antes de rodar, o flow é validado contra a instância real. |
| 3 | 0:09 | Run now: the platform authorizes every call | Run now asks for your password once; from then on, IRIS itself authorizes every call. | O Run now pede sua senha uma vez; dali em diante, a própria IRIS autoriza cada chamada. |
| 4 | 0:15 | 3 checks in parallel, 2 servers | Three integrity checks start together, one of them on a second IRIS server. | Três integrity checks começam juntos, um deles num segundo servidor IRIS. |
| 5 | 0:30 | Join: all must succeed, then the report | The join waits for all of them, then releases the final report. | O join espera todos e só então libera o relatório final. |
| 6 | 0:38 | Every step keeps its result | Every step keeps its result: here, a security report with its findings first. | Cada step guarda seu resultado: aqui, um relatório de segurança com os achados primeiro. |
| 7 | 0:44 | The run tells its own story | The run log tells what happened, in order, in the platform's own words. | O log do run conta o que aconteceu, em ordem, com as palavras da plataforma. |
| 8 | 0:49 | History of every run | And every past run is one click away. SentaiTask: maintenance as flows, not lists. | E todo run antigo está a um clique. SentaiTask: manutenção como flows, não como listas. |
