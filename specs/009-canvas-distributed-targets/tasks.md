# Tasks: Canvas Screens for Distributed Targets (frontend)

**Input**: [plan.md](plan.md), [spec.md](spec.md), spec 008 [contract](../008-distributed-targets/contracts/api-delta.md).

**Tests**: REQUIRED (TDD): unit tests first for pure modules; e2e per story group against the
compose stack (`iris` + `iris-target`). Every task ends with
`cd frontend && npm run generate:tokens && npm test && npx playwright test` after
`bash scripts/publish-canvas.sh`. No test is removed; spec 002/007 evidence files regenerated by
the suite are restored unless intended.

**Hard rules**: no business logic in the browser; refusals verbatim; no credential in
storage/cookies/URL; components never call `fetch` (only `client.ts`/`session.svelte.ts`).
